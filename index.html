Rivages des Morts

Un jeu d'action en pixel art, vu de dessus, jouable dans le navigateur. On explore le Yomi, l'au-delà japonais, et on affronte ses yokai seul, en coop à trois ou en duel. Je m'occupe du game design, de l'univers et du code.

Page du jeu →

Le combat

Rendu avec Babylon.js. La logique du combat est séparée de l'affichage : elle tourne dans le navigateur, sur un serveur ou dans un duel en ligne.

Le multijoueur

Coop à trois en pair à pair (WebRTC). Pour le duel, un netcode à rollback : chaque joueur anticipe les actions de l'autre et corrige si besoin.

Les outils

Ennemis, objets et quêtes sont décrits en JSON. J'ai écrit des scripts Node.js pour les sprites, l'équilibrage et les tests.

La mise en ligne

Chaque modification passe par une pull request vérifiée automatiquement, puis le jeu est déployé sur GitHub Pages.

src/net/rollback.ts · extraitduel en ligne

Pendant un duel, seules les commandes des joueurs passent par le réseau : sept nombres à chaque pas de jeu.

/** Une commande en sept nombres : direction (au millième),
 *  visée et sol visé (au centimètre), boutons. */
type Packed = number[];

function pack(frame: InputFrame): Packed {
  let flags = 0;
  BUTTONS.forEach((key, i) => {
    if (frame[key]) flags |= 1 << i;
  });
  const r = (x: number, k: number) => Math.round(x * k);
  return [r(frame.move.x, 1000), r(frame.move.z, 1000),
          r(frame.aim.x, 100), r(frame.aim.z, 100),
          r(frame.aimGround.x, 100), r(frame.aimGround.z, 100),
          flags];
}
